## 🛠️ How to Use

### Compiling C++ Programs

```bash
# Navigate to specific subject folder
cd ADS/6_BTree

# Compile the program
g++ btree.cpp -o btree

# Run the program
./btree
```

### Running AI Programs

```bash
# Navigate to AI folder
cd AI/8_PuzzleProb

# Compile and run puzzle solver
g++ puzzle.cpp -o puzzle
./puzzle
```
