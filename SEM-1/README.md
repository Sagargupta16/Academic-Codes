## 🛠️ How to Use

### Compiling C++ Programs
```bash
# Navigate to the specific program directory
cd "C++ OOPS Project"

# Compile the program
g++ UnitConversion.cpp -o UnitConversion

# Run the program
./UnitConversion
```

### Running R Programs
```bash
# Navigate to R Programming folder
cd "R Programming"

# Open R console and run scripts
R
source("script_name.R")
```
