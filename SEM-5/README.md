## 🛠️ How to Use

### Setting Up Deep Learning Environment

```bash
# Create virtual environment
python -m venv dl_env
dl_env\Scripts\activate

# Install deep learning packages
pip install tensorflow keras pytorch numpy pandas matplotlib seaborn scikit-learn jupyter

# Start Jupyter Notebook
jupyter notebook
```

### Machine Learning Setup

```bash
# Create ML environment
python -m venv ml_env
ml_env\Scripts\activate

# Install ML packages
pip install scikit-learn pandas numpy matplotlib seaborn jupyter plotly

# For additional libraries
pip install xgboost lightgbm catboost
```

### IoT Development Setup

```bash
# Install IoT development tools
pip install paho-mqtt requests flask

# For hardware simulation
pip install RPi.GPIO gpiozero  # For Raspberry Pi
# Arduino IDE for microcontroller programming
```
